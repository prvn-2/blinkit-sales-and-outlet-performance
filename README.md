# 🛒 Blinkit Sales and Outlet Performance Analysis

## 📌 Project Overview
This project analyzes **Blinkit's sales and outlet performance** using SQL for data exploration and Power BI for interactive dashboarding. It examines how factors such as item type, item fat content, outlet size, outlet type, and outlet location tier influence overall sales performance. The goal is to transform raw retail data into clear, actionable business insights that support data-driven decision-making.

## 🎯 Project Objectives
- Understand overall sales performance across products and outlets.
- Identify top-performing and underperforming outlets, item types, and locations.
- Analyze the impact of outlet size, outlet type, and location tier on sales.
- Explore customer preferences (e.g., low fat vs. regular fat items).
- Build an interactive Power BI dashboard to visualize KPIs and trends.
- Provide business recommendations based on data insights.

## 📊 Dataset Description
The dataset contains transactional and outlet-level information used to evaluate Blinkit's sales performance. Key fields typically include:

| Column | Description |
|--------|-------------|
| Item Identifier | Unique ID for each item |
| Item Weight | Weight of the item |
| Item Fat Content | Low Fat / Regular |
| Item Visibility | % of total display area allocated to the item |
| Item Type | Product category (e.g., Snacks, Dairy, Frozen Foods) |
| Item MRP | Maximum Retail Price of the item |
| Outlet Identifier | Unique ID for each outlet |
| Outlet Establishment Year | Year the outlet was established |
| Outlet Size | Small / Medium / High |
| Outlet Location Type | Tier 1 / Tier 2 / Tier 3 |
| Outlet Type | Grocery Store / Supermarket Type 1/2/3 |
| Item Outlet Sales | Total sales generated by the item at that outlet |

The raw dataset is available in the [`datasets`](./datasets) folder.

## 🗃️ SQL Analysis
SQL was used to clean and explore the dataset before visualization, including:
- Handling missing values (e.g., Item Weight, Outlet Size).
- Standardizing inconsistent category labels (e.g., "low fat", "LF", "Low Fat").
- Aggregating sales by item type, outlet type, outlet size, and location tier.
- Identifying top and bottom performing outlets and product categories.
- Writing queries to validate the KPIs shown on the Power BI dashboard.

All queries are available in the [`SQL`](./SQL) folder.

## 📈 Power BI Dashboard
An interactive Power BI dashboard was built to visualize sales and outlet performance, featuring:
- KPI cards for quick performance snapshots.
- Filters/slicers for outlet type, outlet size, location tier, and item type.
- Trend charts showing sales by outlet establishment year.
- Comparative visuals across outlet types and locations.

The `.pbix` file is available in the [`PowerBI`](./PowerBI) folder.

## 📌 Key KPIs
- **Total Sales**
- **Average Sales per Item**
- **Number of Items Sold**
- **Average Item Rating / Visibility**
- **Sales by Outlet Type**
- **Sales by Outlet Size**
- **Sales by Location Tier (Tier 1 / 2 / 3)**
- **Sales by Item Fat Content**

## 💡 Key Insights
- Certain item types (e.g., Fruits & Vegetables, Snack Foods) consistently drive the highest sales.
- Medium-sized outlets tend to generate stronger overall revenue compared to small or high-sized outlets.
- Supermarket-type outlets outperform standard grocery stores in total sales volume.
- Location tier plays a significant role, with certain tiers showing notably higher sales performance.
- Consumer preference leans toward specific fat-content categories, indicating shifting buying behavior.

## 🔄 Project Workflow
1. **Data Collection** – Gather raw Blinkit sales and outlet data.
2. **Data Cleaning (SQL)** – Handle missing values, fix inconsistencies, and standardize fields.
3. **Exploratory Analysis (SQL)** – Aggregate and query data to uncover patterns.
4. **Data Modeling (Power BI)** – Import cleaned data and build relationships.
5. **Dashboard Design** – Create visuals, KPI cards, and interactive filters.
6. **Insight Generation** – Interpret results and document key findings.
7. **Documentation** – Summarize methodology and results in the `Documentation` folder.

## ▶️ How to Run the Project
1. Clone this repository:
   ```bash
   git clone https://github.com/prvn-2/blinkit-sales-and-outlet-performance.git
   ```
2. Navigate to the project folder:
   ```bash
   cd blinkit-sales-and-outlet-performance
   ```
3. **For SQL analysis:** Open the scripts in the `SQL` folder using your preferred SQL client (e.g., MySQL Workbench, SQL Server Management Studio) and run them against the dataset in the `datasets` folder.
4. **For the dashboard:** Open the `.pbix` file in the `PowerBI` folder using [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
5. Explore the interactive visuals, filters, and KPIs.
